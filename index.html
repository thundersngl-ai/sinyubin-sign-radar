⚙️ 자동 검색 연결 안내

이 ZIP에는 GitHub Actions용 매일 실행 워크플로와 공개 Google News RSS 검색 스크립트가 포함돼 있어요. GitHub 저장소에 올리고 Pages를 켜면 정적 앱으로 공개할 수 있어요. 검색 결과는 뉴스/웹 색인 중심이므로, 중고거래 사이트 전체를 빠짐없이 찾는 검색기가 아닙니다.
